## Órbita — Arena de supervivencia

Juego 3D de supervivencia en una arena cuadrada. Defiende tu lado, devuelve la esfera y sobrevive a tres rivales controlados por CPU. Cada piloto tiene tres vidas; la partida termina si pierdes las tres o si eres el último piloto en pie.

### Cómo jugar

- **Móvil:** desliza el control inferior para mover tu nave de izquierda a derecha.
- **Teclado:** usa las flechas izquierda/derecha o `A`/`D`.
- Pulsa el botón de pausa o `Esc` para pausar.
- Cada 10 segundos sin pérdida de vidas, aparecerá otra pelota o las pelotas acelerarán.

### Ejecutar localmente

Abre `index.html` en un navegador moderno o sirve la carpeta con un servidor HTTP local, por ejemplo:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`. Three.js y las fuentes se cargan desde CDN, así que se necesita conexión a internet.
